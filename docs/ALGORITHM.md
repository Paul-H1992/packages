# 装箱算法设计与取舍

## 1. 问题定义

输入：

- 一组包装箱（内长 `L`、内宽 `W`、内高 `H`、限重 `M`，可选单价）；
- 一个订单（已按 SKU 合并的货品集合），每件货品有两种形态：
  - **瓶装**：直立圆柱，直径 `d`、高 `h`，体积按 `π(d/2)²h` 计；
  - **盒装**：长方体，`l × w × h`。

输出：

- 使用哪种箱型、用几个；
- 每件货品的 `(x, y, z)` 坐标、所属层号；
- 方案整体的填充率、总重、最高堆高、未装/超规货品。

硬约束：

1. 所有货品必须在箱内：`0 ≤ x`、`x+w ≤ L`，`y/l`、`z/h` 同理；
2. 任意两件货品不得重叠；
3. **瓶装轴线始终竖直**，不得旋转；
4. 圆柱之间允许相切（六边形排布时外接矩形会重叠，但实体不重叠）。

软约束（启发式目标）：

- 同 SKU 成层，层高一致，层顶面平整（便于人工/机械码放）；
- 层内尽量密排，减少边角浪费；
- 箱数少、填充率高。

## 2. 为什么不用通用 3D bin packing 库

通用库（py3dbp、D-Wave CQM 示例、DeepPack3D 等）把物品当作**可旋转长方体**，
优化目标通常是「最小箱数」或「最大体积利用率」。它们与本文约束的冲突点：

| 冲突 | 说明 |
| --- | --- |
| 可旋转 | 通用算法会尝试 6 种朝向；瓶装必须竖直，只能有一种朝向 |
| 圆柱近似 | 把圆柱当外接长方体，密度按方阵算，浪费约 10%~15% 的平面空间 |
| 乱序堆叠 | 追求填充率会把物品塞进各种缝隙，结果无法按层复现，人工装箱对不上 |
| 不支持分层 | 没有「第几层、层高多少」的概念，无法生成可执行的装箱单 |

所以本项目自研**分层网格装箱**，把「可执行性」放在「极致填充率」之前。
通用库仍然有价值：若后续出现**纯盒装、允许旋转**的场景，可以并行调用 py3dbp
作为对照方案，取两者中更优者。

## 3. 算法流程

```
optimize_order(items, cartons, cfg):
    packable = [i for i in items if 存在 carton 能放下 i]
    oversize = items - packable            # 单件都放不下的货品，单独报告
    for carton in cartons:
        plans, leftover = pack_into(carton, packable)
        score = objective(plans, leftover)
    best = argmin(score)
    if best.leftover:
        plans += pack_into(其他箱型, best.leftover)   # 混合箱型补齐
    return plans
```

```
pack_into(carton, items):
    pool = [(item, qty), ...]
    while pool 非空:
        plan = pack_carton(carton, pool)       # 扣减 pool
        if plan 为空: break
        plans.append(plan)
```

```
pack_carton(carton, pool):
    z = 0; layers = []
    while z + 最小货品高度 <= H:
        layer = plan_layer(carton, pool, z)    # 扣减 pool
        if layer 为空: break
        layers.append(layer)
        z += layer.height
```

```
plan_layer(carton, pool, z):
    1. 主 SKU = argmax( 单层可放件数 × 底面积 × 高度 )
       候选底面 = 瓶装 (d, d) / 盒装 (l, w) 与 (w, l)
    2. 用点阵铺满：
         瓶装 hex   : 行距 = (d+gap)·√3/2，奇偶排横向偏移 (d+gap)/2
         瓶装/盒装 square : 行距 = 列距 = 边长 + gap
    3. 六边形排布时外接矩形互相重叠 → 直接返回，不做缝隙回填
    4. 否则用 MaxRects 把更矮的其他货品填进剩余矩形：
         - 只允许 height ≤ 本层层高的货品，保证层高不变
         - Best-Short-Side-Fit 选位，放不下就换下一个 SKU
    返回 (placements, 层高)
```

### 3.1 六边形点阵（圆瓶最密排布）

设直径 `d`、间隙 `g`、节距 `p = d + g`：

- 偶数排：圆心 `x = d/2 + i·p`，`y = d/2 + j·p·√3/2`
- 奇数排：横向再偏移 `p/2`
- 相邻排圆心距 `= √((p/2)² + (p·√3/2)²) = p`，即圆柱刚好相切

单层容量在 `L × W` 上约为 `L·W / (p²·√3/2)`，比方形对齐多约 `2/√3 − 1 ≈ 15.5%`
（受边界影响会略低）。

### 3.2 MaxRects 缝隙回填

维护一组互不重叠的空闲矩形。放置一个 `w × l` 的矩形时：

1. 在所有能放下的空闲矩形中，选「短边剩余最小」的位置（Best-Short-Side-Fit）；
2. 用该矩形切分所有与它相交的空闲矩形（左/右/下/上四块）；
3. 删除被其他空闲矩形完全包含的碎片。

复杂度 `O(n²)`（n 为层内物品数），对单层几十到几百件足够快。

### 3.3 选箱目标

| objective | 排序键 |
| --- | --- |
| `cartons`（默认） | 剩余件数 → 箱数 → 填充率（高优先） |
| `volume` | 剩余件数 → 总箱容积 → 箱数 |
| `cost` | 剩余件数 → 总成本 → 箱数（箱型需提供单价） |

「剩余件数」永远第一优先级：先保证装得下，再谈省箱/省钱。

## 4. 复杂度

- 单层：`O(k·P + n²)`，`k` 为候选 SKU 数，`P` 为点阵点数，`n` 为层内件数；
- 单箱：`O((H/h_min) · 单层)`；
- 订单：`O(|箱型| · 每箱) `。

实测示例数据（4 个订单、184 件、4 种箱型）耗时 < 20 ms，属于可忽略量级。

## 5. 正确性保障

`tests/test_packer.py` 用独立于算法的几何校验器逐对检查：

- 所有物品在箱内；
- 瓶装-瓶装：圆心距 ≥ `(d₁+d₂)/2`（圆柱不重叠）；
- 瓶装-盒装：圆心到矩形最近点距离 ≥ `d/2`；
- 盒装-盒装：三轴投影不同时重叠；
- 瓶装外接矩形为正方形且高度等于瓶高（即「直立、未旋转」）。

另外覆盖：六边形容量、层数递增、限重、选箱最少箱数、超规货品标记、订单合并。

## 6. 后续扩展

1. **承压/易碎**：给 `Item` 增加 `fragile`、`max_stack`，在 `plan_layer` 里限制上层 SKU；
2. **重心约束**：按层累计重量重心的 `(x, y)`，超出箱底投影安全区时调整主 SKU；
3. **异形箱/托盘**：把「箱内腔」抽象为可查询的 3D 占据栅格，替换点阵+MaxRects；
4. **混合箱型最优解**：小规模时可用整数规划（OR-Tools CP-SAT）求每种箱型用几个；
5. **装箱单导出**：按层输出 PDF/Excel，供现场作业使用。
